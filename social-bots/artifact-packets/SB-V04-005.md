# Artifact packet — SB-V04-005

Artifact: Real adaptive V0.4 canary
Milestone: V0.4
Owner: Claude-Core / dedicated canary worker
Story points: 3
Priority: **ZERO — hard promotion gate**

## Product rule

V0.4 is NOT complete until this artifact is ACCEPTED.

Unit tests, injected runners, mocked provider output, fixture signals, or deterministic contextual providers cannot satisfy this artifact.

The user explicitly requires at least **one real end-to-end example**.

## Minimum real canary

Use one general persona; default recommendation is `social-a` / **The Ledger** because its evidence requirements make the acceptance easy to audit.

The canary must execute this chain:

1. retrieve one **real current public source** over the network at canary time;
2. persist source URL, retrieval timestamp, HTTP/fetch status and SHA-256 of the actual retrieved bytes;
3. derive a bounded signal/summary from those retrieved bytes;
4. feed that real signal into the Social Bots runtime;
5. invoke the **actual Claude Code subscription provider** through the normal V0.4 adapter — no injected runner and no prewritten model output;
6. parse/validate the returned ReasoningProposal through `REASONING_PROPOSAL_SCHEMA.md`;
7. let deterministic policy choose/allow the bounded action;
8. persist the real decision record;
9. verify no public side effect occurred.

## Source rules

The source must be:
- public;
- current at test time;
- fetched live by the canary process;
- no auth/cookies/private browser state;
- not a local fixture;
- not manually pasted text.

Record:
- URL;
- retrieved_at;
- HTTP/fetch status;
- content length;
- SHA-256;
- a bounded extracted title/summary or evidence excerpt;
- provenance label clearly stating this is a live canary capture.

Because V0.5 collector acceptance is separate, this canary may use a small canary-specific stdlib retrieval path if needed. Do NOT use this artifact to claim V0.5 is accepted.

## Reasoning-provider rules

The adaptive call must be real.

Disallowed:
- injected `runner`;
- fake/substituted JSON;
- fixture provider;
- deterministic baseline/contextual provider;
- manually authored model response.

Required:
- installed `claude` CLI;
- actual subscription/OAuth path authenticated on the host;
- `ANTHROPIC_API_KEY` must be absent from the invocation path;
- no API PAYG credits/keys created;
- bounded non-interactive invocation;
- no tool/effect permissions;
- structured result;
- actual provider identity/version recorded;
- timeout/auth/quota/parse/schema failure => canary BLOCKED, never fake success.

The worker may record only whether ANTHROPIC_API_KEY is present, never its value.

## Decision acceptance

A valid real result may be:
- NO_ACTION;
- RESEARCH_MORE;
- CREATE_CANDIDATE;
- another schema-valid no-effect action that deterministic policy safely handles.

The canary does NOT need to publish anything.

If CREATE_CANDIDATE wins:
- candidate stays local/unpublished;
- `publish_authorized=false`.
