## Goal

Define a Social-Bots-owned reasoning interface for changed-evidence cycles without any SwarmAI dependency.

## Contract requirements

Input must support:
- persona/objective;
- changed evidence summaries/refs;
- relevant state/hypotheses;
- active experiments;
- authority context;
- bounded allowed action vocabulary or proposal schema.

Output must support:
- context-specific candidate actions;
- concise rationale;
- uncertainty/confidence;
- expected value/learning;
- requested evidence or BLOCKED/NO_ACTION;
- schema validation.

Deterministic policy code remains authoritative for safety, spend, posting authority, dedup, leases, scheduling and effect verification.

If no allowed no-additional-spend reasoning provider is available, the interface must fail closed to NO_ACTION/BLOCKED_REASONING_UNAVAILABLE. Never fall back to fake fixed "AI" output and claim V0.4 autonomy.

## Acceptance

- provider unavailable test fails closed;
- malformed output rejected;
- authority-breaching proposal rejected downstream;
- interface contains no SwarmAI import/service/queue/gateway dependency;
- provider identity/attempt/result can be recorded without secrets.
