## Goal

Define a Social-Bots-owned reasoning interface for changed-evidence cycles without any SwarmAI dependency.

## Contract requirements

Input must support:
- persona/objective;
- changed evidence summaries/refs;
- relevant state/hypotheses;
- active experiments;
- authority context;
- bounded allowed action vocabulary or proposal schema.

Output must support:
- context-specific candidate actions;
- concise rationale;
- uncertainty/confidence;
- expected value/learning;
- requested evidence or BLOCKED/NO_ACTION;
- schema validation.

Deterministic policy code remains authoritative for safety, spend, posting authority, dedup, leases, scheduling and effect verification.

If no allowed no-additional-spend reasoning provider is available, the production changed-evidence posture intended to satisfy V0.4 must fail closed to NO_ACTION/BLOCKED_REASONING_UNAVAILABLE. Never fall back to fixed deterministic output and claim V0.4 adaptive autonomy.

A deterministic baseline/contextual provider may exist for tests, diagnostics and comparison only and must be explicitly labeled `adaptive=false`.

## Acceptance

- production changed-evidence default requires adaptive reasoning and fails closed when no adaptive provider is available;
- deterministic baseline/contextual providers are opt-in diagnostics/tests, never the V0.4 production default;
- provider unavailable test fails closed and leaves evidence pending;
- malformed output rejected before scoring/execution;
- authority-breaching proposal rejected downstream;
- interface contains no SwarmAI import/service/queue/gateway dependency;
- provider identity/attempt/result can be recorded without secrets.
