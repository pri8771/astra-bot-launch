# Artifact packet — SB-V22-001

Artifact: Autonomous goal decomposition planner
Milestone: V2.2
Lane: Core
Story points: 5

Goal: translate a high-level strategy goal into bounded artifact/action/experiment work without requiring a human to hand-author every step.

Inputs:
- active strategy;
- evidence/growth opportunities;
- capabilities;
- authority;
- active work/dependencies;
- resource limits.

Output:
- bounded goal tree;
- tasks/artifact intents;
- dependencies;
- expected evidence;
- stop conditions;
- authority requirements.

Acceptance:
- high-level "grow qualified audience" decomposes differently under different evidence;
- no circular dependencies;
- no task exceeds authority;
- blocked account/public actions generate preparatory/read-only work instead of bypass;
- planner can choose NO_NEW_WORK when strategy is adequately covered;
- generated work is schema-valid and deduplicated.
