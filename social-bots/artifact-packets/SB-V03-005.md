## Goal

Allow the three runtimes to host their assigned general/cultural personas without concurrent shared-state corruption or accidental persona workspace mixing.

## Current architecture

Logical isolation inside shared append-only runtime stores remains acceptable if normal production persona-facing reads are structurally persona-scoped and raw whole-runtime enumeration is explicitly admin/internal.

Verified positive progress to preserve:
- `RuntimeState` / `PersonaState` separates shared runtime state from persona-private mutable state;
- same shared signal can be independently considered by multiple personas;
- `PERSONA_SCOPED_READERS` covers the six persona-scoped stores;
- `persona_records(bot, persona, store)` is the authoritative scoped facade;
- `admin_all_records()` exists for deliberate whole-runtime admin/reconciliation reads;
- production dedup is persona-scoped;
- analytics aggregation filters persona;
- worker `_reconcile` uses the explicit admin boundary;
- `tests/test_production_read_paths.py` exercises mixed real cycles, dedup, aggregate and reconciliation behavior;
- Core `f73c337...` removed the ordinary `pipeline.publish_queue` and `analytics.events_for` names and replaced them with explicit `admin_publish_queue` / `admin_events_for` surfaces.

## LEAD-026 remaining structural gap

The packet requires every raw whole-runtime API to be structurally admin/internal or otherwise unavailable as a normal persona-facing interface. Core fixed queue and analytics, but `runtime/state.py` still exposes:

- `RuntimeState.content_history()`

This method reads the full runtime content-history JSONL across all personas. Its docstring says `ADMIN/whole-runtime read`, but the ordinary method name remains directly callable. The contract explicitly rejects comments/docstrings as the enforcement boundary.

The new production-path bypass regression also checks only that `pipeline.publish_queue` and `analytics.events_for` no longer exist. It therefore did not catch `RuntimeState.content_history()` and is too narrow to prove the all-store boundary.

This is the **only concrete V03-005 defect currently known by the lead**, but the repair must audit the complete persona-private raw-reader surface rather than merely rename this one method and assume completeness.
