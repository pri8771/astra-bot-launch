# Artifact packet — SB-V30-002

Artifact: Shared-knowledge and brand-isolation boundary
Milestone: V3.0
Lane: Core + Intelligence integration
Story points: 5

Goal: allow useful shared facts/infrastructure while preventing cross-brand identity, audience, strategy and private-memory contamination.

Required layers:
- brand-private state;
- persona-private audience/community memory;
- shared factual evidence with provenance;
- shared platform/capability metadata;
- portfolio-level aggregate metrics that do not expose private strategy details by default.

Acceptance:
- one shared factual source can be referenced by multiple brands;
- one brand's audience hypothesis cannot be read as another brand's hypothesis;
- content history/dedup remains brand/persona aware;
- shared aggregation cannot overwrite brand-private data;
- access boundary tests.
