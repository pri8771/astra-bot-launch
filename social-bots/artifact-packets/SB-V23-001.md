# Artifact packet — SB-V23-001

Artifact: Temporary specialist worker contract
Strategic checkpoint: V2.3
Lane: Core
Story points: 4

Goal: allow a persistent Social Bot to invoke bounded temporary specialists (researcher, analyst, writer, reviewer, media planner) without SwarmAI.

Required:
- typed task contract;
- explicit inputs/outputs;
- least authority;
- ephemeral lifecycle;
- resource/budget cap;
- evidence/receipt;
- no private strategy-memory write unless explicitly permitted;
- parent bot verifies/adopts/rejects output.

Acceptance:
- specialist cannot exceed granted effect authority;
- failed specialist does not corrupt parent state;
- outputs are attributable and disposable;
- deterministic parent decides whether result changes strategy/action.
