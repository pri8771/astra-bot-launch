## Interfaces

Runner CLI over scripted evidence histories (no live inputs). Pipeline: scripted evidence fixtures → `strategy_lifecycle.transition` / `is_authoritative` → `strategy_decay.expiry_check` → `strategy_reconcile.reconcile` (on a scripted contradictory pair) → `strategy_cooldown.check` → `strategy_rollback.evaluate_rollback_condition`/`execute`. Bundle: `manifest.json` (source SHA, command, `classification: "fixture"`, sha256 of every scripted input/output), plus one JSON per scenario run.

## Deterministic vs model responsibility

Entirely deterministic. The runner accepts no live provider and no live evidence source — everything is scripted fixture data, matching this slice's engineering-only scope.

## Fail-closed behavior

- Any input not labeled `provenance="fixture"` is refused by the runner; this harness never claims live evidence.
- A scenario that produces no lifecycle transition writes a bundle saying so, rather than omitting the scenario.
- `manifest.json` always carries `classification: "fixture"`; the test asserts a bundle can never omit this field.

## Tests (focused + adversarial)

1. contradictory-evidence scenario → `reconcile` returns `HOLD`, no strategy mutation, bundle records the `HOLD` reason.
2. stale-evidence scenario → `expiry_check` returns `REVIEW_DUE`/`EXPIRED`, `is_authoritative` `False` thereafter.
3. cooldown scenario → a second scripted revision inside the window is blocked by `strategy_cooldown.check`; a later one outside the window succeeds.
4. rollback scenario → `evaluate_rollback_condition` returns `True`, `execute` restores the prior version with a receipt.
5. rollback-condition-unresolvable scenario → `HOLD`, no rollback.
6. platform-unavailable scenario → `PLATFORM_CHANGED` from `expiry_check`.
7. persona-scope scenario: two personas run through the same harness in one invocation, never cross-contaminate.
8. manifest hash verification: re-hashing every listed file matches `manifest.json`.
9. the runner refuses a scripted input mislabeled `provenance="evidence"` — this harness is fixture-only.
