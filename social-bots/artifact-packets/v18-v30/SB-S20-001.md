## Goal

Implement immutable `StrategyState` versions with persona scope, evidence refs, supersession and rollback links, plus an active-version pointer and append-only history.

## Dependencies

Engineering (must exist on the implementation branch): `runtime/paths.py`, `runtime/jsonstore.py`, `runtime/leasing.py` (accepted V0.3/V0.4 base).  
Canonical index lists `SB-V19-005`; that is an **operational** gate that applies to `SB-S20-007` / `SB-V20-004`, not to this engineering slice (see `V23_CRITICAL_PATH.md` §3 for the proposed correction).

## Owned paths (new files only)

- `runtime/strategy.py`
- `tests/test_strategy_store.py`

No edits to `decision.py`, `state.py`, `paths.py`.

## Interfaces

Input: `bot`, `persona` (validated with the same regex as `paths._SAFE`), objective, weight maps, evidence refs (dicts, never raw numbers), optional `fence`.  
Output: `StrategyState` dataclass exactly per spec §2.1; files:

```
state/<bot>/strategy/<persona>/v0001.json   immutable version
state/<bot>/strategy/<persona>/HEAD.json    {"active_version": int|None, "updated_at": iso}
state/<bot>/strategy/<persona>/HISTORY.jsonl {version, event, proposal_id?, verdict_id?, sha256, at}
```

Functions: `new_initial`, `save_version`, `load_version`, `active`, `history`, `set_active`, `admin_all_strategies` (explicit cross-persona admin reader, mirrors `isolation.admin_all_records`).

`save_version` refuses to overwrite an existing version file (raises `StrategyVersionExists`); it records the file's sha256 in HISTORY so later tampering is detectable by `history()` (`{"tampered": true}` flag on mismatch, never silent repair).

## Deterministic vs model responsibility

Entirely deterministic. No provider, no model call. Proposals come from S20-003; this slice only stores/reads.

## Fail-closed behavior

- Unsafe `persona`/`bot` → `ValueError`, nothing written.
- Version gap or duplicate (`version != active+1` when superseding) → refuse.
- Weight maps that do not sum to 1.0 (±1e-6) or contain negatives/non-finite → refuse.
- `evidence_refs` containing bare numbers/strings → refuse (must be dicts with at least `kind`+`id` or an `evidence_id`).
- `fence` supplied and lost → `leasing.FenceLost`, no partial files (write version → HISTORY → HEAD, all inside one `fenced_commit`).

## Tests (focused + adversarial)

1. create v1 → v2 (`supersedes=1`) → `active()` returns v2; `load_version(1)` unchanged byte-for-byte.
2. duplicate version write refused; original bytes untouched.
3. tampered v1 file → `history()` flags mismatch.
4. two personas on one bot: separate dirs, `active()` never crosses; `admin_all_strategies` sees both and is the only path that does.
5. unsafe persona `../x` refused before any mkdir (assert no path created under `SBOTS_HOME`).
6. fence-loss test using `leasing.Fence` from `tests/test_fencing.py` pattern: zero durable writes.
7. weight validation cases (negative, >1, NaN, sum≠1).
8. `SBOTS_HOME` temp-dir isolation for every test.
