## Interfaces

```
class Collector(Protocol):
    def capture(self, ref: dict) -> dict: ...          # returns CaptureReceipt dict (CROSS_LANE §2)
class FixtureCollector(Collector): ...                 # no network; provenance="fixture"; deterministic content_hash
class ResearchSpecialist:
    role = "researcher"
    def run(self, contract, sandbox, *, collector: Collector | None = None, provider=None,
            deadline=None) -> WorkerResult
```
Behavior: for each `input_artifacts[*]` of kind `source_candidate`, call `collector.capture` (default `FixtureCollector`), write `evidence/<n>.json` (`EvidenceRef` + receipt), then write `outputs/research_result.json` `{"schema": "ResearchResult/1", "evidence_refs": [...], "summary": [...], "unresolved": [...]}`. `provider`, when supplied, must already be a `specialist_budget.BudgetedProvider` (S23-007) and may only *rank/summarize* captured evidence; it cannot add sources that were not captured (any evidence ref in the provider output that is not in the captured set is dropped and recorded in `limitations`).

## Deterministic vs model responsibility

Capture, hashing, file layout, result schema: deterministic. Optional provider: summarization/ranking only, validated against captured refs. Default run is fully deterministic.

## Fail-closed behavior

- Contract role ≠ `researcher` → `RoleMismatch`, nothing run.
- Collector failure → receipt with `retrieval_status="failed"` (CROSS_LANE §2 "failed evidence cannot support a claim"); the result is `COMPLETED` with `unresolved` populated, never a fabricated capture.
- Deadline exceeded (S23-007 `Deadline`) → `TIMED_OUT`, partial evidence kept as-is, `outputs` lists only fully written files.
- Any attempt to import/call `pipeline`, `decision`, `content_dir` or `publish` paths is absent by construction; test greps the module for those names.
- `effect_attempts` is always 0; the adapter has no method that could produce an effect.

## Tests (focused + adversarial)

1. Two fixture sources → two evidence files + result; sha256 in `WorkerResult.outputs` verifies.
2. Collector raising on one source → that ref `failed`, other succeeds; `result="COMPLETED"`, `unresolved` lists the failure.
3. Provider output referencing an uncaptured evidence id → dropped, `limitations` notes it.
4. Deadline of 0s → `TIMED_OUT`, outputs only contain complete files.
5. Role mismatch (`writer` contract) → `RoleMismatch`.
6. Writes go only under scratch (snapshot compare of `SBOTS_HOME`).
7. Module source contains none of: `pipeline`, `decision`, `content_dir`, `publish`, `enqueue`.
8. Persona scope: `bounded_context_refs` for another persona resolved through `PersonaSnapshotResolver` → `ScopeError` propagates as `FAILED` result with error, no evidence written.
9. Missing input artifacts → `COMPLETED` with empty evidence and `limitations=["no sources"]` (no invented sources).
