## Goal

Expire/decay stale strategic assumptions based on evidence age, platform change and seasonality. This module only reports; it never mutates strategy state or triggers a transition itself.

## Dependencies

- SB-S21-001

Engineering: requires the listed slice present on the implementation branch as a new file.

- `runtime/strategy_decay.py`
- `tests/test_strategy_decay.py`

## Interfaces

`decayed_confidence(state, evidence, now, half_life_hours)` (reuses the half-life formula pattern from `audience.py::_decayed`, copied rather than imported per spec §1); `expiry_check(state, availability, now) -> "OK"|"REVIEW_DUE"|"EXPIRED"|"PLATFORM_CHANGED"`.

## Deterministic vs model responsibility

Pure arithmetic and date math. No provider.

## Fail-closed behavior

- `state.confidence is None` → `decayed_confidence` returns `None` (missing≠zero; never decays a confidence that was never set).
- Every entry in `evidence_refs` unresolvable → `decayed_confidence` returns `None`, never `0.0`.
- A platform in `platform_weights`/`priority_audiences` marked unavailable in `availability` → `expiry_check` returns `"PLATFORM_CHANGED"` even when age-based checks would otherwise say `"OK"`.
- `review_by`/`expires_at` unset → age-only decay never forces `"EXPIRED"`.

## Tests (focused + adversarial)

1. confidence decays monotonically with age per the half-life formula; exact value matches a hand-computed fixture.
2. `state.confidence is None` → `decayed_confidence` returns `None`, not `0.0`.
3. all evidence unresolvable → `None` returned, never treated as zero confidence.
4. `expiry_check` returns `EXPIRED` once past `expires_at`.
5. `expiry_check` returns `REVIEW_DUE` once past `review_by` but before `expires_at`.
6. `expiry_check` returns `PLATFORM_CHANGED` when a weighted platform becomes unavailable, even for a fresh strategy.
7. `expiry_check` returns `OK` for a fresh, available, unexpired strategy.
8. persona-scope: decay computation for persona A never reads persona B's evidence store.
9. stale evidence (older than a fixture threshold) lowers `decayed_confidence` relative to the same evidence set backdated to "now".
