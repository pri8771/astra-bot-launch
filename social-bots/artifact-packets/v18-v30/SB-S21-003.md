## Goal

Reconcile opposing evidence across experiments/time windows without deleting prior strategy history. The reconciler only produces a verdict and reasons; the caller decides what, if anything, to do with it.

## Interfaces

`ContradictionRecord`; `reconcile(refs_a, refs_b, *, evidence, config) -> ReconcileOutcome` with verdict in `HOLD | REQUEST_MORE_EVIDENCE | PREFER_A | PREFER_B` plus `reasons`. Never deletes or mutates either input evidence set or any strategy version.

## Deterministic vs model responsibility

Deterministic comparison (recency, sample count/quality via `EvidenceIndex.age_hours`/resolved fields, per-`config` thresholds). No provider.

## Fail-closed behavior

- Either side unresolvable via `evidence.resolve` → treated as missing, contributes nothing to that side's case, never counted as support.
- Both sides equally strong within `config` tolerance → `HOLD`, never an arbitrary tie-break toward A.
- Insufficient evidence on both sides → `REQUEST_MORE_EVIDENCE`.
- Output never includes a mutated or deleted version of either input ref list (asserted by identity/content check).

## Tests (focused + adversarial)

1. `refs_a` clearly stronger (more recent, more resolvable, higher sample count) → `PREFER_A` with reasons.
2. symmetric `refs_a`/`refs_b` → `HOLD`.
3. both sides thin (below the evidence floor) → `REQUEST_MORE_EVIDENCE`.
4. one side entirely unresolvable → treated as missing, not as a loss for that side, and `reasons` says so explicitly.
5. stale evidence on one side (older than `config.max_evidence_age_hours`) discounted relative to fresh evidence on the other side.
6. calling `reconcile` never mutates `refs_a`/`refs_b` in place (input identity/content unchanged after the call).
7. persona-scope: reconciling persona A's evidence never resolves refs against persona B's evidence index.
8. a contradiction spanning two time windows (one experiment run twice with opposite results) resolves to `HOLD` or `REQUEST_MORE_EVIDENCE`, never silently picking the more recent run without stating recency as the reason.
