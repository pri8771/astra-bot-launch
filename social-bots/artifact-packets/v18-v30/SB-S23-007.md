## Deterministic vs model responsibility

Deterministic guards. The wrapped provider is the only non-deterministic component and is fully counted/gated.

## Fail-closed behavior

- No manifest + adaptive provider → `ProviderNotAuthorized` at construction; zero calls made (assert wrapped provider's call count is 0).
- Budget 0 → first `propose` raises before delegating.
- `ANTHROPIC_API_KEY` in env → refuse (mirror `authorization.posture_violations`).
- `SpawnGuard` cannot be bypassed via `allowed_tools`: `validate_contract` already refuses `spawn_specialist`; this guard is defense-in-depth at call time.
- `Deadline` with `time_budget_s <= 0` → already expired.
