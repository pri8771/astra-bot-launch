## Interfaces

Per spec §2.6:
```
SpecialistAuthority(read_context_refs=True, write_scratch=True, emit_result=True)   # frozen; no other fields
ROLE_TOOLS: dict[str, frozenset[str]]                                                # spec §5.2
new_contract(*, bot, persona, parent_run_id, role, objective, bounded_context_refs, expected_output_schema,
             time_budget_s, model_call_budget=0, allowed_tools=None, denied_tools=(), input_artifacts=(),
             stop_conditions=(), ttl_s=None, provenance="fixture") -> WorkerContract
validate_contract(c) -> list[str]
validate_result(r, c) -> list[str]
```
`new_contract` generates `worker_id = f"w-{uuid4().hex[:12]}"`, sets `scratch_scope = worker_id`, `external_effect_budget = 0` (not a parameter — it cannot be set), `allowed_tools` defaults to `ROLE_TOOLS[role]` and any requested tool outside that set is an error, `expires_at = created_at + (ttl_s or time_budget_s * 2)`.

`validate_result` checks: `worker_id`/`parent_run_id`/`bot`/`persona`/`role` match the contract; `effect_attempts == 0`; `calls_used <= model_call_budget`; every `outputs[*].path` is relative and contains no `..`; `result` in the enum; `finished_at >= started_at`; `sha256` present for every output.

## Deterministic vs model responsibility

Entirely deterministic. No provider is constructed here. `model_call_budget` is carried for S23-007 to enforce.

## Fail-closed behavior

- `new_contract(authority=Authority(...))` or any kwarg/dict containing `can_public_post`, `can_spend`, `can_message_users`, `external_effect_budget` → `TypeError`/`ContractError` before construction.
- `bounded_context_refs` containing a key matching `(?i)(credential|token|password|cookie|secret|session)` → refused (specialists never receive credentials by reference either).
- `allowed_tools ∩ denied_tools ≠ ∅`, tool outside role allowlist, role outside enum, `expires_at <= created_at`, `scratch_scope != worker_id`, unknown keys → `validate_contract` errors; callers must not persist an invalid contract (test asserts no file written by `Sandbox.create` in S23-002 when errors exist).
- `validate_result` mismatch → errors; S23-006 must treat any error as REJECT.

## Tests (focused + adversarial)

1. `new_contract` for each of the six roles → valid, `allowed_tools == ROLE_TOOLS[role]`, `external_effect_budget == 0`.
2. Requesting `allowed_tools={"publish"}` → error; `{"spawn_specialist"}` → error.
3. Passing `decision.Authority()` as `authority` → raises; passing `{"can_public_post": True}` anywhere in kwargs → raises.
4. `bounded_context_refs=[{"session_cookie": "..."}]` → refused.
5. `denied_tools` overlapping `allowed_tools` → error.
6. `expires_at` before `created_at` (via `ttl_s=-1`) → error.
7. `validate_result`: `effect_attempts=1` → error; `calls_used > budget` → error; output path `../escape.json` or `/abs` → error; `worker_id` mismatch → error; `result="DONE"` (not in enum) → error.
8. Round-trip `as_dict()` → JSON → dataclass without loss; unknown key on reload → error (no silent widening).
9. Persona scope: contract `persona="b"` with result `persona="a"` → error.
10. `SpecialistAuthority` is frozen and `hasattr(SpecialistAuthority(), "can_public_post")` is False.
