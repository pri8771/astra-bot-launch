## Goal

Represent proposed, active, cooling, superseded, rolled-back and expired strategies explicitly. The lifecycle module owns status transitions and the single "is this strategy authoritative right now" check that a later runtime hook will consult.

## Dependencies

- SB-V20-004

Engineering: the index dependency SB-V20-004 is an OPERATIONAL gate; engineering dependency is SB-S20-004 and SB-S20-006 only.

## Owned paths (new files only)

- `runtime/strategy_lifecycle.py`
- `tests/test_strategy_lifecycle.py`

## Interfaces

`TRANSITIONS` table (allowed `(from, to)` pairs among `PROPOSED|ACTIVE|COOLING|SUPERSEDED|ROLLED_BACK|EXPIRED`); `transition(state, to, *, reason, fence=None) -> StrategyState` (persists the status change via the same version/HEAD/HISTORY shape as SB-S20-001, inside `fence.fenced_commit` when given); `is_authoritative(state, now) -> bool` (True only when `status == ACTIVE` and, if set, `now < expires_at`).

## Deterministic vs model responsibility

Entirely deterministic table lookup. No provider.

## Fail-closed behavior

- Transition not present in `TRANSITIONS` → refuse, state unchanged, nothing written.
- Transition to the same status → refuse (a no-op is not a transition).
- `is_authoritative` on a `None` state or a state with a missing/unknown status → `False`, never raises and never defaults to `True`.

## Tests (focused + adversarial)

1. every allowed transition in `TRANSITIONS` succeeds and is durable.
2. every disallowed pair (e.g. `SUPERSEDED→ACTIVE`, `EXPIRED→ACTIVE`) rejected, state unchanged.
3. `is_authoritative` is `True` only for `ACTIVE` and unexpired; `False` for `COOLING`/`SUPERSEDED`/`ROLLED_BACK`/`EXPIRED` and for `ACTIVE` past `expires_at`.
4. `is_authoritative(None, now)` → `False`, no exception.
5. persona-scope: transitioning persona A's strategy never touches persona B's HEAD/HISTORY.
6. fence-loss on transition → `FenceLost`, no partial write.
7. self-transition (`PROPOSED→PROPOSED`) rejected.
8. `HISTORY.jsonl` records the transition event with `reason`, matching SB-S20-001's HISTORY shape.
