**Version gate:** V0.4

## Purpose

Prove that the **adaptive** V0.4 reasoning path changes proposals/rankings for meaningful persona/workspace and evidence differences while holding unrelated variables constant. This suite is acceptance evidence for adaptive behavior; deterministic contextual heuristics may be retained only as supplemental engineering diagnostics.

## Required acceptance cases

1. **Persona-only divergence**
   - Use the same exact evidence snapshot, objective, runtime state, prior history, duplication state and policy posture.
   - Change only persona/workspace.
   - Exercise the adaptive provider path (`adaptive=true`).
   - Demonstrate a material proposal/ranking/decision difference for at least three persona/workspace comparisons, including at least one cultural/Primandir workspace.

2. **Evidence-only divergence**
   - Use the same exact bot/runtime, persona/workspace, objective, prior history, duplication state and policy posture.
   - Change only the evidence.
   - Exercise the adaptive provider path (`adaptive=true`).
   - Demonstrate a material proposal/ranking/decision difference attributable to evidence.

3. **Policy/authority invariants**
   - Every proposal passes `REASONING_PROPOSAL_SCHEMA.md` validation.
   - Provider recommendation remains advisory; deterministic policy retains effect authority.
   - No provider output may grant publish/message/purchase/destructive authority.
   - No public effect occurs.

4. **Provider evidence**
   - Provider identity and receipt must prove the adaptive route actually ran.
   - `ContextualReasoningProvider` / `contextual-deterministic-v1` (`adaptive=false`) does **not** satisfy final acceptance.
   - Fixture/injected-runner tests may remain as diagnostics but do not substitute for adaptive-path proof.
