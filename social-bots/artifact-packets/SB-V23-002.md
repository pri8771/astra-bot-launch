# Artifact packet — SB-V23-002

Artifact: Specialist worker lifecycle / sandbox / evidence
Milestone: V2.3
Lane: Core
Story points: 5

Depends on SB-V23-001.

Goal: implement temporary specialist workers as bounded Social Bots components.

Required lifecycle:
CREATE -> ASSIGN -> RUN -> RETURN -> VERIFY -> ADOPT/REJECT -> RETIRE.

Each specialist gets:
- typed task;
- minimum context;
- least authority;
- bounded turns/time/resource budget;
- explicit output schema;
- no persistent identity unless promoted by a later artifact.

Acceptance:
- researcher cannot publish;
- writer cannot mutate strategy;
- reviewer cannot rewrite evidence;
- failed specialist leaves parent state unchanged except truthful failure receipt;
- parent verifies before adopting result;
- retired worker has no continuing lease/authority;
- no SwarmAI dependency.
