## What was built

New `runtime/growth_evaluator.py` — turns real analytics/experiment/audience
evidence into bounded recommendations about where to spend **attention and
learning effort**. It exposes a clean interface for the lead to reconcile with
Core's SB-V20-001 strategy engine; it does NOT integrate into Core's decision
loop (per lane contract, awaiting a lead-assigned integration checkpoint).

### Inputs (`OpportunityInput`)
platform, format, optional experiment id, per-platform normalized performance
(or None if unmeasured), audience support/confidence, learning-question flag,
evidence refs.

### Outputs (`evaluate`)
- ranked `growth_opportunities` (only those with measured performance);
- ranked `learning_opportunities` (open questions / unmeasured lanes);
- `allocation` — attention/effort weights (sum ≈ 1.0) across platform/format/
  experiment, each with reasons, evidence refs and uncertainty;
- `blocked` (unavailable destinations) and `insufficient_evidence` lists;
- `spend_authorized: False` (hard invariant).

### Guarantees
- **No monetary spend** is authorized; weights are attention share, and there is
  no spend/buy/pay/budget function.
- **Missing data is not zero:** a missing performance metric stays `None`, keeps
  the lane out of *growth* ranking, and routes it to *learning* instead.
- **No recommendation on insufficient evidence** (no perf + no audience + no
  learning question => excluded).
- **Learning value can beat short-term reach** via `learning_weight`.
- Unavailable destinations are BLOCKED and never allocated.

## Known limits + integration note (explicit)
- Inputs are supplied by the caller from SB-V13-001 metrics, SB-V15-001
  experiments and SB-V14-001 audience memory; this engine invents no metric.
- Integration into Core's autonomous decision loop / SB-V20-001 strategy engine

  interface for ChatGPT lead to reconcile across the two lanes at an integration
  checkpoint. Strategy changes must remain evidence-based, reversible,
  attributable and bounded — this engine only recommends attention/learning
  allocation; it authorizes no effect and no spend.
