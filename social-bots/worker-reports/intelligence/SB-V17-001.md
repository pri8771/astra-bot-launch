## What was built

New `runtime/community.py` — safely observe community signals, decide whether a
response is useful, and retain community memory, with a hard wall between reading
and any public response effect.

### Boundaries enforced
- **Read/observe separated from response effect.** `CommunitySignal.ingest()`
  accepts only `fixture` / `read-only-evidence` sources. There is deliberately
  NO posting / voting / following / liking / engagement function — a regression
  asserts the module exposes none.
- Spam / abuse / unsafe / content-policy signals gate to `NO_ACTION`.
- A response is only ever a `ResponseProposal` carrying confidence and an
  authority requirement. `clear_for_effect()` requires an explicit
  `AuthorizedRoute` AND a passing deterministic review; even when cleared the
  module performs no public effect (`CLEARED_NO_EFFECT_PERFORMED`).
- Full linkage: signal / thread / parent / content / persona / account.
- Community themes are aggregated from SAFE signals only and feed audience
  memory through a real evidence ref (no invented confidence).

### Decision table
- unsafe/abuse/spam/policy => NO_ACTION;
- none/low value => NO_ACTION;
- medium value => OBSERVE_ONLY (update memory, no response);
- high-value safe => PROPOSE_RESPONSE (authority + review required to ever act).

## Tests / evidence
- `python3 -m unittest discover -s tests` -> **120 passing** (was 109; +11).
- Acceptance regressions: read-only observation works without authority; ingest
  rejects non-read-only source; unsafe/spam/low-value => NO_ACTION; high-value
  proposes but requires authority; no-authority blocks effect; authorized but
  failing review blocks effect; authorized+reviewed clears but performs no
  effect; no engagement/voting/follow functions exist; themes from safe signals
  only feed audience evidence.

## Known limits (explicit, not faked)
- Classification is deterministic heuristic (keyword gates), clearly labeled;
  an adaptive classifier can feed the same decision interface later. Public
  response remains an unauthorized external gate — this module never posts.
