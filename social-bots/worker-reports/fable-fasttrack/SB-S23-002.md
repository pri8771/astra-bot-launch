## What was built

- `Sandbox(contract)`: refuses an invalid contract in `__init__` with no filesystem access; `create()` makes a `0o700` tree (`context/`, `inputs/`, `outputs/`) and refuses an existing directory (a worker id is never reused).
- Containment (`_resolve`) runs before any write: absolute paths, `.`/`..`/empty components, backslashes, NUL, drive prefixes, any symlinked component, and out-of-root resolution raise `SandboxEscape`. `write`/`read` accept only regular files; `list` skips symlinks.
- `materialize_context(resolver)`: each bounded ref becomes `context/<n>-<sha8>.{json,bin}` with sha256; returns ref copies plus file metadata, never live objects; runs once; on any resolver failure writes `context/FAILED.json` and raises `ContextError` so the lifecycle must not run the adapter.
- Resolvers: `DictContextResolver` (fixture, deep copies) and `PersonaSnapshotResolver(bot, persona)` which reads only through `runtime.isolation.persona_records` for its own persona and only the `SNAPSHOT_KINDS` persona-scoped stores; any other persona/bot/kind raises `ScopeError`. No `PersonaState`/`RuntimeState`, `state_dir` or `admin_*` reader is reachable.
- `retire(keep=...)`: kept entries are containment-validated and read first; on any failure returns `FAILED` with nothing copied and the scratch left for audit; otherwise copies kept outputs plus `INDEX.json` (sha256, identity) to the receipts tree and removes the scratch (`rmtree` does not follow symlinks). Second call returns the recorded status; post-retire I/O is refused.
