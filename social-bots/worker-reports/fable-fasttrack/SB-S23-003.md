## What was built

- `Collector` protocol (`capture(ref) -> CaptureReceipt dict`) and `FixtureCollector` (no network; `provenance="fixture"`; configurable raise/forge for adversarial tests).
- `validate_receipt`: rejects malformed receipts and forged provenance (a `fixture` capture claiming anything stronger than `fixture`/`unverified`, or `trusted_operational` without a trusted transport); invalid receipts are recorded as `failed`.
- `evidence_ref_from_receipt`: CROSS_LANE §1 `EvidenceRef` derived from the receipt.
- `ResearchSpecialist.run(contract, sandbox, *, collector, provider, deadline, ledger)`: role/contract/sandbox/provider identity checks; refuses to run on a sandbox whose context failed; honours tool narrowing (`write_scratch` required, `capture_source` optional → truthful `unresolved`); per source writes `evidence/NNN.json` (`EvidenceCapture/1`: input, evidence_ref, receipt) via `Sandbox.write`; only `ok` captures become `evidence_refs`, everything else is `unresolved`; optional `BudgetedProvider` may only rank/summarize captured ids (invented ids dropped + limitation; provider faults are limitations, not failures); deadline checked between steps → `TIMED_OUT` with only fully written files in `outputs`; writes `outputs/research_result.json` (`ResearchResult/1`); returns a `WorkerResult` with ledger counts.
