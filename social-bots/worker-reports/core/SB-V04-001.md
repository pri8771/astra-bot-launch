## What changed (`runtime/reasoning.py`, `runtime/decision.py`)
1. **Adaptive-required contract.** New `adaptive_required()` reads
   `SBOTS_REASONING_REQUIRE_ADAPTIVE` (default False, so tests/legacy/debug may
   use baseline explicitly). When True and the resolved provider is not adaptive
   (i.e. baseline), `resolve_provider()` returns an `_UnavailableProvider`, so the
   engine fails closed to `BLOCKED_REASONING_UNAVAILABLE` rather than running
   fixed heuristic scoring and pretending it is adaptive autonomy.
2. **Proposal schema validation before scoring/execution.**
   `reasoning.validate_proposal` / `validate_candidate`, called by
   `decision.run_cycle` immediately after a proposal is produced and *before* it
   is scored or executed. Rejections (fail closed, signal not consumed):
   - action not in the bounded `ACTION_VOCAB`;
   - numeric fields not finite / outside `[0,1]` / wrong type (bool/str rejected);
   - empty alternatives;
   - `recommended_action` unsupported or not among the proposed alternatives;
   - payload smuggling authority (`can_public_post`, `can_spend`, `publish_authorized`,
     `token`, `credential`, … ) or carrying unknown keys (allow-list: signal,
     draft, experiment, notes);
   - `CREATE_CANDIDATE` without a `signal`.
   The block record carries a truthful `block_reason`.
3. **Policy remains authoritative.** Validation is defense-in-depth; the
   deterministic layer (`decision`/`pipeline`/`leasing`) still independently owns
   authority, publication gates, dedup, leases, scheduling and verification. A
   proposal is only a suggestion.
4. **No SwarmAI dependency** — no swarm import/service/queue/gateway (asserted by a
   test that scans import lines, ignoring prose disclaimers).
