## What each new test proves
1. `test_forced_fact_review_failure_blocks_experiment_and_queue`
   - **Fault injection**: `pipeline.fact_check` is forced to fail for one cycle.
     Rationale: the natural pipeline always coalesces a `source_ref`, so a
     genuine fact failure cannot arise from signal content alone; injecting the
     failing check is the honest way to prove the *gate* stops the candidate.
     `pipeline.review()` aggregation and the real deterministic gate both run.
   - Asserts: `outcome=withheld`, no experiment file, no experiment index,
     empty publish queue, `learn.updated=false`, gate_failures names `fact`.
2. `test_forced_voice_review_failure_blocks_experiment_and_queue`
   - **Real end-to-end failure** (no monkeypatch): the captured signal text
     contains persona `social-b`'s banned move `snark`, so the actual
     `pipeline.voice_review` fails. Same downstream-stop assertions; gate_failures
     names `voice`.
3. `test_worker_receipt_for_forced_voice_failure_is_not_success`
   - Runs the full `worker.run_one_unit` path; finish receipt records
     `outcome=withheld`, `candidate_succeeded=false`, and the queue stays empty.

A shared `_assert_no_downstream_effect` helper enforces that every failure mode
produces the identical truthful stop (no experiment registration, no publish
queue entry, no success, no learning), so future modes cannot silently diverge.
