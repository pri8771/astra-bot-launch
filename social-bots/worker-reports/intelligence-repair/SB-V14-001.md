## Scope

Repair of the SB-V14-001 audience memory per INTELLIGENCE_WAVE1 §4 and the
LEAD-014 finding that `Hypothesis` had no bot/persona field and persisted under a
single `memory/<bot>/audience/` namespace (no isolation).

## Changes (`runtime/audience.py`)

1. **Persona/workspace scope.** `Hypothesis` now carries persistent `bot` +
   `persona` fields (with a `scope` view). `new_hypothesis(bot, persona, segment,
   statement)` requires both.
2. **Persona-scoped persistence.** Memory is stored under
   `memory/<bot>/audience/<persona>/`. `save(bot, persona, hyp)` refuses a
   hypothesis whose own scope does not match; `load(bot, persona, id)` returns
   `None` for another persona's hypothesis; new `list_hypotheses(bot, persona)`
   returns only that persona's. Two personas on one runtime cannot overwrite or
   blend each other's private hypotheses.
3. **Segment allowlist.** `validate_segment` now enforces an allowlist of safe
   content/context dimensions (`ALLOWED_SEGMENT_DIMENSIONS`) instead of a
   sensitive-attribute blacklist; unknown/sensitive dimensions and sensitive
   values are rejected, and an empty segment is rejected.
4. **Fork fix.** `fork_hypothesis` no longer copies the parent's contradicting
   evidence as the fork's *supporting* evidence. Contradiction of A is not
   positive evidence for an arbitrary alternative B: the fork starts `unlearned`
   and only becomes learned from its own supporting observations. The triggering
   contradiction is retained solely as provenance (`origin_contradiction_refs`).
   The fork inherits the parent's persona scope unless re-scoped.
5. **Confidence identifies scope + refs.** Every `confidence()` result now
   includes `scope` (bot/persona) and the `evidence_refs` it was derived from.

Observation/inference separation, no-fake-learning, decay, and bounded
confidence preserved. No Core files modified.
