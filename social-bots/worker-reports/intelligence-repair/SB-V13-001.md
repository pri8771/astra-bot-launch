## Scope

Repair of the SB-V13-001 normalized analytics brain per INTELLIGENCE_WAVE1 §3
and the LEAD-014 finding that `MetricValue` had no semantic kind and
`aggregate_semantic()` summed all PRESENT observations (failing snapshot safety).

## Changes (`runtime/metrics.py`)

1. **Semantic kinds.** Added `CUMULATIVE_SNAPSHOT` / `DELTA` / `GAUGE` / `RATE`.
   Every PRESENT normalized metric declares a `metric_kind`, resolved from an
   explicit per-platform `kinds` table (per-call `raw_kinds` override), with a
   fail-closed default of `cumulative_snapshot` (never naively summed).
2. **Kind-aware aggregation.** `aggregate_semantic` now reduces each
   `(platform, kind)` group by its kind:
   - `delta` → summed (additive across windows);
   - `cumulative_snapshot` → reduced to the latest snapshot **per series**
     (platform/account/persona/content), then summed across series — never
     summed over time;
   - `gauge` / `rate` → mean of the latest-per-series values.
   Missing/not-supported still excluded (never counted as 0) and reported.
3. **Snapshot→delta derivation.** `derive_delta_from_snapshots(prev, curr, sem)`
   converts a snapshot to a delta only with a valid earlier **comparable**
   snapshot (same series, ordered windows, non-decreasing), and records the
   derivation (source observation ids, series key, windows). Non-comparable /
   decreasing / missing inputs → MISSING with a reason, never a fabricated delta.
4. Derived ratios now carry `metric_kind=RATE`. Raw retention, missing-vs-zero,
   no-false-equivalence, provenance, staleness and traceability preserved.

`analytics.py` and all Core files unchanged.
