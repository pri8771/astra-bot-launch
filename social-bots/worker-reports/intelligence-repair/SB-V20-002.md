## Scope

Repair of SB-V20-002 growth evaluator/allocation engine per INTELLIGENCE_WAVE1
§8 and the LEAD-014 finding that `OpportunityInput` lacked persistent bot/persona
scope and the result did not carry the full accepted cross-lane
authority/availability/cost contract.

## Changes (`runtime/growth_evaluator.py`)

1. **Persistent scope + typed contract.** `OpportunityInput` now carries required
   `bot` + `persona`, plus `required_authority`, `cost_class`, and `provenance`.
   Outputs are typed `GrowthOpportunity` records aligned with
   `CROSS_LANE_INTERFACES.md` §7 (opportunity_type, expected_growth_value,
   expected_learning_value, confidence, uncertainty[], required_authority,
   evidence_refs[], operational_availability, cost_class, bot/persona). Every
   growth/learning/allocation/blocked/insufficient record echoes bot+persona, so
   two personas on one runtime stay distinguishable.
2. **Typed evidence construction.** `opportunity_from_evidence(...)` builds an
   OpportunityInput from accepted upstream records (SB-V13 `NormalizedObservation`,
   SB-V15 learning ref, SB-V14 confidence result), validates that every record
   shares the (bot, persona) scope, collects evidence refs, and marks
   `provenance="evidence"`.
3. **Arbitrary numeric input is test-only.** Direct `OpportunityInput`
   construction defaults to `provenance="test-only"`. Under
   `evaluate(..., require_evidence=True)` a test-only input can never become a
   GROWTH opportunity (only learning / insufficient).
4. **Stale/invalid evidence => learning, not growth.** `opportunity_from_evidence`
   demotes a stale metric observation (SB-V13 `is_stale`) to a learning signal
   and never to growth; a performance value with no backing observation is
   likewise not growth-eligible.
5. **No invented authority/cost/scope.** `required_authority`, `cost_class` and
   `operational_availability` are carried from inputs/availability, not
   fabricated, so Core's strategy-revision interface can consume the output
   directly. Preserved: no monetary spend (hard invariant, no spend API),
   missing≠zero, unavailable→blocked, learning-can-beat-reach.

No Core files modified.
